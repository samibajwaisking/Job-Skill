# Job Platforms Reference

Use this when searching for jobs in Step 3 of the LinkedIn Job Hunter workflow.

## Global Platforms

| Platform | Best For | Search URL Pattern |
|----------|----------|--------------------|
| LinkedIn Jobs | All industries, professional roles | linkedin.com/jobs/search/?keywords= |
| Indeed | Volume listings, all levels | indeed.com/jobs?q= |
| Glassdoor | Company culture + salary info | glassdoor.com/Job/ |
| Monster | Traditional roles | monster.com/jobs/search/ |
| ZipRecruiter | US/UK focused | ziprecruiter.com/Jobs/ |

## Search Strategy by Experience Level

### Fresh Graduate / Entry Level
- Search terms: "entry level", "fresh graduate", "trainee", "junior", "associate"
- Platforms: Indeed, LinkedIn, Rozee.pk (for Pakistan)

### Mid-Level (3-7 years)
- Search terms: role title + skill combination
- Platforms: LinkedIn, Indeed, Glassdoor, remote platforms

### Senior / Lead (7+ years)
- Search terms: "senior", "lead", "principal", "manager", "head of"
- Platforms: LinkedIn, Hired.com, Toptal, ExecThread

### Freelancer
- Primary: Upwork, Fiverr Pro, Toptal
- Secondary: LinkedIn freelance, PeoplePerHour
